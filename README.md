# Basic supermarket e-commerce

My first academic project – 2010
Basic supermarket e-commerce site with shopping list comparison.

## Prerequisites

Make sure Docker and Docker Compose are installed and Docker Desktop is running.
    
## Run Locally

1. Clone the project

```bash
  git clone git@github.com:brlivramento/ecommerce_supermarket.git
  cd ecommerce_supermarket
```

2. Build docker

```bash
  docker compose up --build
```
